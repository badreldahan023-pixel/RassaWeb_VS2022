مشروع تخرج: منصة رِصّة (RASSA) لإدارة وتسهيل توريد مستلزمات المطاعم والكافيهات والمخابز
ASP.NET Core MVC + C# + ADO.NET + SQL Server (Visual Studio 2022)
================================================================================

طريقة التشغيل بضغطة واحدة:
1. فك الضغط عن هذا الملف المضغوط (Extract All) في أي مجلد على جهازك.
2. اضغط مرتين على ملف: (RassaWeb.sln) أو ملف (اضغط_هنا_لفتح_المشروع_في_Visual_Studio.bat).
3. سيفتح المشروع مباشرة داخل برنامج Visual Studio 2022.
4. اضغط على زر التشغيل الأخضر (F5 أو Ctrl + F5).
5. ميزة ذكية مدمجة: سيقوم المشروع تلقائياً بالاتصال بـ SQL Server على جهازك وإنشاء قاعدة البيانات (RassaDB) وتعبئتها بـ (10 مخازن معتمدة + 6 أقسام + 32 منتجاً + طلبات موثقة بالـ Blockchain) تلقائياً فور التشغيل!
   (ويوجد أيضاً ملف RassaDB_FullDatabaseScript.sql إذا أردت تشغيله يدوياً على SSMS).
